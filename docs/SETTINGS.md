# Settings

Open **Settings** from the title screen's Set Up Puzzles page or from the top right of the puzzle board. Most settings have a **?** button beside them that explains them in the game. Wheel-specific settings are on **Wheel Settings**, and the new options are on **Extra Features**.

## Appearance
| Setting | What it does | Default |
|---|---|---|
| **Game Name** | The name shown on the puzzle board. A name other than WHEEL OF FORTUNE also hides the logo on the title screen. | WHEEL OF FORTUNE |
| **Backdrop** | The scenery behind the board and wheel. You can also click the board's right light pillar to change it. | studio |
| **Color Scheme** | The color of the board frame, wheel trim and category box (blue, gold, silver). You can also click the board frame. | blue |
| **Blue Tiles** | When a letter is correct, tiles light up blue and each is clicked to reveal. Off shows letters instantly. | on |

## Gameplay
| Setting | What it does | Default |
|---|---|---|
| **Vowel Price** | What a vowel costs. | $250 |
| **House Minimum** | What a winner banks if their round score is lower. | $1,000 |
| **Shot Clock** | A timer from 1 to 30 seconds on the board for player decisions. | none |
| **No More Vowels/Consonants** | Announces when there are no vowels or no consonants left in the puzzle. | on |
| **Spanish Ñ** | Makes Ñ a selectable letter for Spanish puzzles. | off |
| **Special Score Bonuses** | The show's bonus for a Same Letter puzzle, and 5× for solving all three Triple Toss-Ups. | off |
| **Solve Button** | *reveal* shows the puzzle at once. *verify* asks you to type the answer and checks it. | reveal |

## Puzzle tools
**Delete All Puzzles** (asks to confirm), **Show All Puzzles**, and **Sound Effect Settings** (preview a sound, or replace it with your own audio file).

## Wheel Settings
| Setting | What it does | Default |
|---|---|---|
| **Values Range** | The range of regular dollar values on the wheel. | $500–$900 |
| **Number of Bankrupts** | How many Bankrupt wedges each wheel has (set per round type). | 2 |
| **Free Play Wedge** | Adds a Free Play wedge. | off |
| **Wild Card** | Adds the Wild Card item. | off |
| **Gift Tag** | Adds the Gift Tag item (a prize of your choice). | off |
| **$5,000 Sliver** | A wedge split into two Bankrupts and $5,000. | off |
| **$5 Wedge** | Adds a $5 wedge. | off |
| **Claimable** | *once* removes an item from the wheel when claimed; *multiple* leaves it for others to earn. | once |

## Extra Features
| Setting | What it does | Default |
|---|---|---|
| **Turn Tracker** | Shows whose turn it is and passes it automatically. | on |
| **Million Dollar Wedge** | Adds the Million Dollar Wedge to the first three wheels. | off |
| **Bonus Wheel** | The 24-envelope prize wheel; **Edit Bonus Prizes** changes the prizes. | on |
| **Pick-a-Category Bonus** | The contestant picks one of three categories before the Bonus Round. | on |
| **Import Puzzles from Text** | Adds many puzzles at once. | |
| **Save/Load game file** | Moves a game between computers. | |
| **Share Game** | On the Settings screen: copies a link that opens your game for anyone, with optional scores and current puzzle. | |

## Players
Use the **+ / −** buttons on the puzzle board to switch between 2, 3 and 4 players. Click a name to edit it.
