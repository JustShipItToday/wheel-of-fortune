# Troubleshooting & FAQ

## Where is my game saved?
Automatically, in the browser you are using on that computer. Use the same browser and the same address on game day. To move a game elsewhere, use **⋯ → Save game file**, then **Load game file** on the other computer. If you clear your browser's site data, the saved game is cleared too.

## My puzzles disappeared.
You may be on a different browser, a private/incognito window, or a different address. Open the game where you set it up, or load a saved game file.

## There is no sound.
Click anywhere on the page once (browsers block sound until you interact), check **⋯ → Sound on**, and check the computer's volume. If you share a tab on a video call, make sure tab audio is shared.

## Can I use it offline?
Yes. Download `index.html` from this repository and open it in your browser. It is the entire game in one file.

## Can I use it on a projector or a TV?
Yes. Use full screen (**⋯ → Full screen**, or F11). The game scales to fit the screen. Try your real setup before the day: projectors vary in brightness and color.

## What does it work on?
An up-to-date Chrome, Edge, Firefox or Safari on a computer. A phone or tablet will open it but the game is designed for a large screen with a mouse.

## Something looks wrong or doesn't work.
- Don't use the browser's **Back** button or reload mid-game; use the on-screen buttons.
- If the game seems stuck, check for a dialog box that is waiting for an answer.
- Report a bug by opening an issue on this repository with what you clicked and what you saw.

## Are the wheel and logo the same as the original?
No. The wheel and logo are redrawn for this edition and are close lookalikes, not the original artwork. The wheel's values and landing behavior follow the original game.

## Are the default Bonus Wheel prizes official?
No. They are an approximation of the show's range ($40,000–$100,000 plus cars). Edit them under **Extra Features → Edit Bonus Prizes**.

## Can I change the name of the game?
Yes: **Settings → Game Name**.
