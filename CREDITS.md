# Credits

## Wheel of Fortune Web Edition
**Developer:** Avi Lindenboim  
**Revised:** October 2026

Completely redone for the web: rebuilt to run in any browser, with a redrawn wheel and logo, plus a turn tracker, Million Dollar Wedge, Bonus Wheel, Prize Puzzle, pick-a-category Bonus Round, and puzzle import.

## The original
**Wheel of Fortune for PowerPoint** (v6.4) was created by **Timothy Hsu (Games by Tim)**, © Games by Tim. This edition is based on his game: the rules, screens, layout, game logic and sound effects all come from his work. Without it, this project would not exist. Thank you, Tim.

**View the original:** https://github.com/TimTree/wheel-of-fortune-ppt

## What is and isn't from the original
| Part | Source |
|---|---|
| Rules, game logic, screens, layout, text | Games by Tim, ported to the browser by Avi Lindenboim |
| Sound effects and music | Games by Tim's original game |
| Wheel and logo artwork | Redrawn from scratch for this edition (not the original artwork) |
| Turn tracker, Million Dollar Wedge, Bonus Wheel, Prize Puzzle, pick-a-category bonus, puzzle import, game file save/load | New in this edition |
| Fonts | [Josefin Sans](https://fonts.google.com/specimen/Josefin+Sans) and [Alfa Slab One](https://fonts.google.com/specimen/Alfa+Slab+One), both under the SIL Open Font License, embedded in the page |
